# EduVerse LMS — Outcome Checklist

- [ ] **Public entry and role routing** — The app provides a landing page, an about-style explanation of the link-based model, clear Teacher/Admin demo entry points, a Student course link, and friendly not-found/error states. Navigation uses real routes and the route manifest stays synchronized.
- [ ] **Teacher dashboard and course control** — Teacher sees course count, unique participants, active access, average score/progress, recent activity, and an activity chart. Teacher can open the course editor, toggle publish/access lock, copy the unique learning link, preview as a student, and export a participant report.
- [ ] **Course builder and lesson content** — Teacher can edit title/description, add and remove content blocks, reorder through the visible builder affordance, and see lesson blocks for text, video, number-line activity, quiz, case study, reflection, and mini-game. Draft/published/access states are explicit.
- [ ] **Student link journey** — Student opens the demo course link, enters name/class, receives a participant profile stored locally, resumes from the same device, sees modules and progress, completes a formative quiz with explanations, and sees the local sync status.
- [ ] **Configurable mini-game studio** — Teacher can change range, operation, question count, levels, points, timer, pass threshold, and assessment mode. Preview uses the current configuration to generate a number-line challenge, supports correct/incorrect playtest, reset, draft save, publish, and add-to-course. Playtests do not create student gradebook records.
- [ ] **Admin controls and branding** — Admin sees platform usage, teacher accounts, demo audit activity, and editable application name/accent color controls with local persistence and an explicit demo-mode note.
- [ ] **Responsive visual system** — Light/dark/system theme is available and remembered; the interface uses playful depth, soft blue/violet/teal/yellow/coral tokens, reduced-motion support, mobile layouts, empty/loading/success feedback, and accessible labels.
- [ ] **Production seam and safety** — No secret keys are shipped client-side. Demo-only persistence is labeled. Typed domain data is separated from presentation so authenticated server actions, managed database tables, RLS, storage, rate limits, and server-side access validation can be added without replacing the screens.

- [ ] **Workspace navigation and block editing correction** — Teacher workspace links use the matching URL route/query state so `/teacher?tab=participants` shows Peserta and `/teacher?tab=analytics` shows Analitik, including direct navigation and switching between tabs. The block editor action opens an actual modal with editable title and description fields, and saving updates the visible block in the draft.

- [ ] **Materi per modul dan Game Library course Operasi Hitung Bilangan Bulat** — Guru dapat mengisi blok per modul dengan teks/instruksi, link YouTube atau Google Drive, link/upload PDF, kuis, tugas, dan game. Siswa membuka setiap modul pada halaman route sendiri; video/link dapat dimuat, PDF ditampilkan dalam viewer, teks tampil sebagai materi, kuis memiliki player tersendiri, dan aktivitas Garis Bilangan, Kartu Muatan, serta Number Line Challenge tersedia dalam Game Library pembelajaran.

- [ ] **Theme parity across routes** — Dark/light mode initializes from the saved browser preference on every route, can be toggled from public and workspace pages, and updates page backgrounds, surfaces, cards, inputs, modals, student views, builder, admin, and game screens rather than only changing text color.

- [ ] **Teacher assessment authoring and synced detail view** — Kuis memiliki halaman builder khusus untuk menambah/menghapus soal, memilih tipe soal termasuk uraian, mengatur opsi dan kunci jawaban, feedback, poin per soal, total skor, percobaan, acak soal, ambang lulus, serta tampil/sembunyikan skor. Editor Aktivitas dan Game memiliki instruksi, tipe respons, rubrik/poin, pilihan game library, gradebook, ambang lulus, dan visibilitas skor. Analitik teacher menampilkan rincian aktivitas dan respons per modul serta modal detail peserta dengan progres, skor, aktivitas, dan item uraian yang perlu dinilai manual.

- [ ] **Game Studio template parity** — Mini-Game Studio menyediakan tiga template yang sesuai materi: Aktivitas Garis Bilangan, Kartu Muatan Positif & Negatif, dan Number Line Challenge. Guru dapat memilih template, mengubah nama, petunjuk, parameter perilaku, ronde, timer, poin, ambang lulus, gradebook, playtest, menyimpan draft per template, publish ke library, dan menambahkan game aktif ke modul.

- [ ] **Game selection and YouTube playback correction** — Editor game memakai registry yang sama dengan Mini-Game Studio, sehingga Aktivitas Garis Bilangan, Kartu Muatan Positif & Negatif, dan Number Line Challenge selalu tersedia dan route siswa membuka game yang benar. Link YouTube dinormalisasi untuk format watch, youtu.be, shorts, live, dan embed; player memakai YouTube privacy-enhanced mode, parameter origin, serta fallback buka link asli jika video membatasi embedding sehingga siswa tidak terjebak error 153.

- [ ] **Separate FPBL activities from game blocks** — Aktivitas Garis Bilangan dan Kartu Muatan Positif & Negatif menjadi blok Game resmi yang membuka Game Library. Tipe Aktivitas memiliki template terpisah: Mengamati & Menanya, Eksplorasi Awal, Investigasi Kelompok, dan Refleksi; setiap template memiliki pertanyaan/kasus, instruksi, bukti yang dikumpulkan, tipe respons, poin, rubrik, serta form respons siswa.

- [ ] **Student responses, module CRUD, and live teacher analytics** — Materi aktivitas interaktif memiliki pilihan jawaban A/B/C dengan kunci, tombol Kirim jawaban, waktu pengiriman, skor otomatis untuk pilihan objektif, serta status review untuk uraian/upload. Assignment juga memiliki area jawaban. Submission disimpan per participant ID dan tampil pada detail peserta guru bersama skor, respons, dan timestamp. Guru dapat menambah/menghapus modul dan materi; modul baru muncul di builder dan ruang siswa, sedangkan analitik serta peserta membaca modul dan submission yang tersimpan, bukan hanya baris statis.
